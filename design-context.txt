================================================================================
 1. PROJECT OVERVIEW
================================================================================

Full-stack fintech MVP monorepo for managing personal finances:
transactions, categories with monthly budgets, and analytics dashboard.

- Backend: Express 5, TypeScript, Prisma 6, SQLite (local) / PostgreSQL (Docker/CI)
- Frontend: React 18, Vite 8, Tailwind CSS 4, Recharts 2, Lucide React
- Testing: Vitest, @testing-library/react, jsdom, coverage thresholds
- CI/CD: GitHub Actions (lint, test:all, build), Codecov, CodeQL, Dependabot, Docker
- Auth: JWT in httpOnly cookie, bcrypt password hashing

 6. TECHNICAL DECISIONS & CONSTRAINTS
================================================================================

=== 6.1 STYLING ===
- Tailwind CSS 4 via @tailwindcss/vite plugin (NOT postcss/tailwindcss v3)
- @theme block in index.css defines all colors (no hardcoded raw hex in components)
- Palette: blue-50..900, indigo-50..900, purple-50..900, gray-50..900
- Status: green-50/500/600/700, red-50/500/600/700, amber-50/500/600
- Theme tokens: sidebar-start, sidebar-end, sidebar-hover, sidebar-active, card,
  card-border, gradient-start, gradient-end, radius-card, radius-button, radius-input
- Font: Inter via Google Fonts
- Components use <button> not <a> for navigation (sidebar uses onNavigate callback)
- cn() utility from lib/utils.ts (clsx + tailwind-merge)
- No CSS modules, no styled-components — all Tailwind utility classes

=== 6.2 FORM CONVENTIONS ===
- Inputs: h-10/11, rounded-xl, border-indigo-100, bg-indigo-50/50
- Focus: ring-2 ring-indigo-400/20
- Buttons: bg-gradient-to-r from-indigo-600 to-purple-600, shadow-lg shadow-indigo-500/25
- Selects: same styling as inputs
- Labels: text-[12px] or text-[13px] font-medium text-gray-600/700

=== 6.3 API CONVENTIONS ===
- All responses: { data: ... } or { data: ..., meta: { page, pageSize, total } }
- Auth: POST /api/auth/{login,register,logout}, GET /api/auth/me
- Transactions: GET/POST /api/transactions, PATCH/DELETE /api/transactions/:id
- GET /api/transactions/summary — returns { data: { totalIncome, totalExpense, balance } }
- Categories: GET/POST /api/categories, PATCH/DELETE /api/categories/:id
- GET /api/categories/status — with ?month=YYYY-MM filter
- POST /api/transactions returns { data: Transaction, budgetAlert: BudgetAlert | null }
- Pagination: ?page=1&pageSize=10&sort=desc&type=&categoryId=&from=&to=
- Errors: { message: string, code?: string }

=== 6.4 PRISMA (SQLite MODE) ===
- provider = "sqlite" (changed from postgresql)
- All Float fields (changed from Decimal)
- type String (changed from enum for Transaction.type)
- No @db.Decimal annotations
- mappers.ts: toMoney() returns value as-is (no Prisma.Decimal conversion)
- budget.ts: <= 0 instead of .lte(0), Prisma.Decimal fallback removed
- routes: import type { Prisma } for types only

=== 6.5 TEST PATTERNS ===
- vi.hoisted() for mock data and mock object
- vi.mock("./api/client") returning { api: apiMock }
- Login helper: type email/password → click "Iniciar sesión"
- All async assertions in waitFor(() => expect(...), { timeout: 15000 })
- Never use findByText with third-arg timeout (doesn't work with jsdom)
- UserEvent v14 for realistic interactions
- ResizeObserver polyfill required for recharts in jsdom

 8. RUNNING COMMANDS
================================================================================

Development:
  npm run dev              — runs both api (4000) and web (5173) concurrently
  npm run dev --workspace @fintech/api   — just the API
  npm run dev --workspace @fintech/web   — just the web app

Testing:
  npm run test             — run web tests only (vitest)
  npm run test:all         — run all tests (api + web)
  cd apps/web && npx vitest --coverage  — run web tests with coverage
  cd apps/web && npx vitest --ui         — interactive UI mode

Database:
  npm run prisma:generate --workspace @fintech/api
  npm run db:dev --workspace @fintech/api   — prisma migrate dev
  npm run db:seed --workspace @fintech/api  — seed demo data

Build:
  npm run build            — typecheck + build both api and web
  cd apps/web && npx vite build  — build web only

Lint:
  npm run lint

Docker:
  docker compose up --build  — full stack with PostgreSQL
  docker compose down -v     — clean shutdown with volume removal
